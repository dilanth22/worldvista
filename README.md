# WorldVista V5

Static Cloudflare Pages site. Build command: `npm run build`; output directory: `dist`; framework: None.

GitHub upload: upload source files and folders to repository root. Do not upload `dist` alongside source. Cloudflare Pages automatically rebuilds from GitHub.

Country search and region filters work. 100+ country entries are available, but only Sri Lanka, Japan and Indonesia have curated 20-place lists. Other countries clearly disclose that detailed recommendations are pending. Premium guides are previews only; no payments or PDF delivery. External Unsplash images require internet access and licensing review for commercial production. SEO scores are not guaranteed.
